\chapter{Введение}
Абсолютная устойчивость описывает поведение линейной динамической части с \emph{априорно неизвестной} нелинейностью, удовлетворяющей лишь общим ограничениям (сектор, ограниченная энергия, монотонность). Задача: гарантировать глобальную устойчивость замкнутой системы для \textbf{всех} допустимых нелинейностей без уточнения их формы.

\chapter{Постановка задачи (формулировка Лурье)}
Рассматривается SISO-система в форме Лурье:
\begin{equation}
    \begin{aligned}
        \dot x &= Ax + b\,\varphi(\sigma),\\
        \sigma &= c^\top x, \qquad y = \sigma,
    \end{aligned}
\end{equation}
где $A,b,c$ описывают линейную часть, а $\varphi(\cdot)$~--- статическая нелинейность. Абсолютная устойчивость означает асимптотическую (или конечную) устойчивость нуля для всех $\varphi$ из заданного класса.

\chapter{Классы нелинейностей}
\begin{itemize}
    \item \textbf{Секторные ограничения} $\varphi(\sigma)\in [k_1\sigma,\,k_2\sigma]$ (частный случай~--- сектор $[0,k]$).
    \item \textbf{Двойное ограничение} (сектор + наклон): $0\le \frac{\varphi(\sigma_1)-\varphi(\sigma_2)}{\sigma_1-\sigma_2}\le k$.
    \item \textbf{Ограниченная производная} $|\dot\varphi|\le \mu$ (используется в критериях Попова / супер-твистинг).
    \item \textbf{Ограниченная энергия} $\int_0^\infty \varphi(\sigma)\sigma\,dt < \infty$.
    \item \textbf{Насыщение / релей} как частный случай сектора $[0,k]$.
\end{itemize}

\chapter{Критерии абсолютной устойчивости}

\section{Круговой критерий}
Для сектора $[0,k]$ передаточная функция линейной части $G(s)=c^\top (sI-A)^{-1}b$ должна быть строго положительно действительной после замыкания: $G(s)/(1+kG(s))$ устойчив и Найквист не охватывает точку $-1/k$ (эквивалентно, образ не пересекает соответствующую окружность). Проверяется частотно или через LMI для положительной действительности.

\section{Критерий Попова}
Для сектора $[0,k]$ существует $\nu\ge 0$, что
\begin{equation}
    \Re\big\{(1+j\omega\nu) G(j\omega)\big\} > -\frac{1}{k}, \quad \forall \omega\in\mathbb{R}.
\end{equation}
Геометрически: Найквист $G(j\omega)$, деформированный множителем $(1+j\omega\nu)$, целиком правее прямой $x=-1/k$.

\section{Частотное неравенство Якубовича–Калмана–Попова (LMI)}
Для устойчивого $A$ и управляемой/наблюдаемой пары $(A,b,c)$ абсолютная устойчивость в секторе $[0,k]$ эквивалентна существованию $P=P^\top>0$, $q\in\mathbb{R}$:
\begin{equation}
    \begin{bmatrix}
        A^\top P + P A & P b - q c\\
        b^\top P - q c^\top & -2q/k
    \end{bmatrix} < 0.
\end{equation}
Это удобно для численной верификации (S-процедура).

\chapter{Практический алгоритм проверки}
\begin{enumerate}
    \item Привести систему к форме Лурье: выделить $\sigma=c^\top x$, нелинейность $\varphi(\sigma)$ и сектор.
    \item Выбрать критерий: Попова (если нужен запас по фазе), круговой (графически), или LMI ЯКП (автоматизированно).
    \item Проверить условие (частотно или LMI). При необходимости подобрать усиление $k$ или фазовый опережатель $(1+j\omega\nu)$.
    \item Подтвердить моделированием на репрезентативных $\varphi$ (насыщение, релей, кусочно-линейные).
\end{enumerate}

\chapter{Краткий пример}
Линейная часть: $G(s)=\dfrac{1}{s(s+2)}$, нелинейность в секторе $[0,1]$. По критерию Попова выбираем $\nu=1{,}2$; численная проверка $\Re\{(1+j\omega\nu)G(j\omega)\}>-1$ выполняется для всех $\omega$, следовательно система абсолютно устойчива для любых $\varphi\in[0,1]$ (релей, насыщение и т.п.).

\chapter{Выводы}
Абсолютная устойчивость гарантирует работоспособность замкнутой системы при неопределённой нелинейности, опираясь только на секторные или энергетические ограничения. Частотные критерии (круговой, Попова) дают наглядные геометрические тесты, а LMI-формы (ЯКП) обеспечивают автоматизированную проверку и применимы к широкому классу объектов. Ключевой шаг — корректное задание сектора для нелинейности.
